# Student Diet & Calorie Log System

An interactive Python-based health tracker designed to assist students in tracking daily calories, calculating body health metrics, and maintaining calorie balances.

## Features
- **Health Analytics**: Automated calculation of BMI, weight status, and customized daily calorie intake targets.
- **Dietary Recommendations**: Category-driven food suggestion system (Underweight, Normal, Overweight).
- **Activity Logging**: Dynamic logging for food consumed and exercise burned.
- **Robust Exception Handling**: Prevents crashes from invalid numerical inputs or unknown food choices.
- **File Logging**: Standardized activity logging recorded into `app.log`.

## Technologies Used
- **Language**: Python 3.8+
- **Modules**: Standard Library (`logging`)
